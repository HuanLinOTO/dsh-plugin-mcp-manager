- **Host 半**：`/api/mcp-manager` 路由（经 `ctx.webServer`）+ `mcp_*` agent 工具（`ctx.tools`）+ 读写 profile `cordis.patch.yml` 的 `@deepseek-ai/dsh-mcp-client` insert 行（配置 HMR 挂载）。
- **Client 半**：注册 Plugins 页 `plugins.row.config` 的「dsh-mcp-manager」行配置卡片（key `@huanlin/dsh-plugin-mcp-manager#dsh-mcp-manager`，`src/client` 参与 typecheck；2026-09-25 自 `settings.section` 迁入，见文末增补）。

## 2026-09-25 增补：`settings.section` → `plugins.row.config`

rc.1 起第三方插件的共享设置/入口统一走 Plugins 页（ui-plugin-manager 声明）的
`plugins.row.config`（kind 'keyed'，key = `<包名>#<行id>`，行 id 为 bundle patch insert 行
`id` 原样透传——页面 `rowConfigKey()` 精确字符串匹配，写错即静默无入口）。本次迁移：

- **注册形态**：`ctx.slots.inject('plugins.row.config', function* () { yield ctx.slots.register({ name, key: ROW_KEY, locale: NS, inject: () => ({}) }, McpPanel) })`
  （interpreters 形态的裸 inject）。**不用** `configForms.whileServed` gating：本插件自身无
  volatile Config（面板管理的是官方 `@deepseek-ai/dsh-mcp-client` 的 insert 行），settings
  describe 会过滤无 form 的 entry → entry 永不被 serve → gating 等于永久撤回贡献。
- **key 派生**：`src/client/row-key.ts` 常量 `PKG_NAME`/`ENTRY_ID`/`ROW_KEY`
  （`@huanlin/dsh-plugin-mcp-manager#dsh-mcp-manager`），三方一致性（cordis.patch.yml 行 id /
  package.json 包名 / host 半插件名）由 `tests/row-key.spec.ts` 守卫。
- **Panel 组件**：props 改为 `PropsRuntime<'plugins.row.config'> & { t? }`；`view: 'summary'`
  返回一行简介纯文本（行详情页描述回退，渲染进 `<p>`，不拉数据），`view: 'page'` 渲染完整
  面板；卡片不读 `props.form`（对本插件恒 undefined），数据继续走自建 `/api/mcp-manager`
  HTTP 通道（host 半路由/registry/工具零改动）。
- **locale**：新增 `summaryLine` key（zh/en + 19 语言 better-locale 覆盖词典同步补齐）。
- **peer/manifest**：`@deepseek-ai/dsh-client-ui-settings`（type-only）→
  `@deepseek-ai/dsh-client-ui-plugin-manager`（type-only，`^0.1.7-rc.1`，optional）；
  `dsh.client.inject` 增补 `@deepseek-ai/dsh-client-ui-plugin-manager`（informational edge）。
- **验证**：`pnpm typecheck` / `pnpm test` / `pnpm run build` 全绿；src/ 内 `settings.section`
  零匹配；产物契约（无 default 导出、`window.__ModuleLoader__.load` 包裹）保持。
